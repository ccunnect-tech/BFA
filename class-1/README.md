# Class 1 tasks

| Folder | What it is |
|--------|------------|
| [`live/`](live/) | Challenges we do together **during class** |
| [`homework/`](homework/) | Tasks you finish **after class** |

Each task is a `.py` file. The instructions are written as comments at the top. Write your code **below the line** that says `Write your code below this line`.

## How to do and submit a task

1. In **GitHub Desktop**, click **Current Branch**, then **New Branch**. Name it `class-1-yourname`, for example `class-1-priya`.
2. Open the task file in VS Code and write your code.
3. Run it to test it:
   - Mac: `python3 class-1/live/01_age_in_10_years.py`
   - Windows: `python class-1/live/01_age_in_10_years.py`
4. In GitHub Desktop, write a short summary (for example `Finish live challenge 1`) and click **Commit**.
5. Click **Publish branch** the first time, and **Push origin** after that.
6. Tell us in the course group when you have pushed. We will open your branch and check your work.

Do the same for the homework files. Keep using the same branch.
